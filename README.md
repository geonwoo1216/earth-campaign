# 🌍 지구 지킴이 캠페인 — 앱 설명서 (발표자료용)

이 문서는 **발표자료를 만드는 친구를 위한 참고 자료**예요.
우리가 만든 앱(웹)을 직접 열어 보면서, 아래 내용을 발표자료에 옮겨 쓰면 돼요!

- 앱 주소(실행): https://geonwoo1216.github.io/earth-campaign/campaign.html
- 만든 트랙: 지구·환경 (디자인씽킹 × 생성형 AI)

> ⚠️ 주의: 이 앱을 만든 우리는 학생 이름·학교를 문서에 적지 않아요.
> 발표자료에도 팀 이름(조 번호)만 쓰는 걸 잊지 마세요!

로비에 들어오면 오른쪽에 내 캐릭터가 있고, 가운데에 **네모 기능 버튼 4개 + AI 버튼**이 있어요.

| 버튼 | 무엇을 하나요? |
|---|---|
| ♻️ 분리배출 게임 | 섞인 쓰레기를 올바른 통에 넣는 게임 |
| 🎨 환경 포스터 | 그림을 그리고 전시관에 올리는 기능 |
| 🧠 지구온난화 퀴즈 | 환경 문제를 풀고 점수를 얻는 퀴즈 |

오른쪽 옆판에는

- 🐣 내 별명(닉네임)
- ✨ 내 캐릭터 꾸미기

이 있어요.

## 4. 각 기능 자세히

### ♻️ 분리배출 게임
- 쓰레기가 나오면 **맞는 통(종이·플라스틱·캔·유리·음식물·일반)** 을 눌러요.
- 한 판에 10문제 (일반 8 + 어려운 2) 가 매번 새로 나와요.
- **🤔 어려운 문제**는 구분하기 힘든 쓰레기예요. 맞히면 보석 2배!
- 목숨이 3개(❤️) 있고, 점수가 저장돼요.

### 🧠 지구온난화 퀴즈
- 매번 다른 문제 15개 (일반 12 + 👑 보스 3)
- 보스 문제는 중1 수준의 어려운 문제! 보라색 상자로 표시돼요.
- 맞힐 때마다 보석, 끝나면 최고 점수도 저장돼요.

### 🎨 환경 포스터 (만들기 + 전시관)
- 붓으로 그리고, 🧽 지우개, 🔤 글씨, 🐳 스티커, 📏 크기 조절
- 색은 여러 색 + 무지개색 자유 선택
- ↩️ 되돌리기, 🗑️ 그림 리셋
- 완성하면 **전시관에 올리기** → 전시관에 걸리고 보석 +15

### 📺 학습 영상
- 🎬 우리가 만든 애니메이션 4편
- 📰 진짜 뉴스 5편 (SBS·KBS·JTBC·비디오머그)
- 📚 과학 강의 5편 (김상욱 교수·EBS 등)
- 진짜 영상은 유튜브로 재생돼요(인터넷 필요).

### 🤖 AI 지구친구
- 환경 낱말로 질문하면 답해 주는 AI (지식 88+ 주제)
- 예: "블루카본이 뭐야?", "갯벌은 왜 중요해?" 도 대답해요.

### ✨ 내 캐릭터 꾸미기
- 머리·상의·하의·신발·얼굴 장식·허리·등·피부 **122개 아이템**
- 아이템은 💎 보석으로 사요.

### ⚙️ 설정
- 🎵 배경 노래 켜기/끄기
- 🔊 효과음 켜기/끄기
- 💎 **보석 코드**: 환경 낱말(수수께끼 힌트)을 입력하면 보석 +30
- 🌍 **특별 코드**: `save the earth` → 보석 +10,000

### 🎁 숨은 재미 (이스터 에그)
- 화면 오른쪽 위 **🌞 해님**을 누르면 "탄소 줄이는 실천법 8가지"가 나와요. (처음엔 보석도 줌)

## 5. 보석과 랭킹

- 게임·퀴즈·포스터·영상·코드로 보석 💎 을 모아요.
- 보석으로 캐릭터 옷을 사 입혀요.
- 점수가 쌓이면 등급이 올라가요:
  🌱 새싹 지킴이 → 🌿 초록 지킴이 → 💧 하늘 지킴이 → ⭐ 별빛 지킴이 → 🌻 햇살 지킴이 → 🌍 지구 대장

## 6. 발표할 때 추천 순서 (짧은 소개용)

1. 인트로: "지구가 아파요. 우리는 놀면서 지구를 지키는 법을 만들었어요."
2. 로비: 네모 버튼 소개 (한눈에)
3. 분리배출 게임을 1판 시범
4. 퀴즈 보스 문제 1개 보여주기
5. 포스터 전시관 (우리가 만든 작품)
6. 학습 영상 (뉴스·강의 한 개 틀기)
7. AI에게 질문 하나 던지기
8. 마무리: "작은 실천이 모이면 지구가 웃어요!"

## 7. 이 앱의 기술 (간단히)

- 파일 하나로 동작하는 웹앱이에요.
- 그림은 SVG로 직접 그리고, 게임·퀴즈·저장은 웹 안에서 동작해요.
- 저장은 브라우저에 기록돼요 (인터넷 없이도 게임 진행·보석 저장).
